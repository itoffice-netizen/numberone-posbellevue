# แอป ครัวพอดี POS (Android) — จอแคชเชียร์ + จอลูกค้าแยกกัน
แอปเล็กๆ ห่อระบบ POS ด้วย WebView; ถ้าเครื่องมีจอที่ 2 (Sunmi/iMin ฯลฯ) จะเปิดหน้าจอลูกค้าไปที่จอนั้นเอง (Presentation API)
- จอแคชเชียร์: ระบบ POS ปกติ (รองรับเลือกไฟล์โลโก้ และลิงก์ intent: ของ RawBT)
- จอที่ 2: โลโก้ร้าน + ยอดบิล/QR ตอนเช็คบิล ไม่รับการสัมผัส
- ครั้งแรกกรอกที่อยู่ เช่น https://โดเมนของคุณ/ชื่อร้าน/ ; เปลี่ยนทีหลัง: แตะมุมซ้ายบน 7 ครั้ง

## สร้างไฟล์ APK (เลือก 1 วิธี)
1. GitHub: สร้าง repo ใหม่ อัปโหลด "เนื้อหาในโฟลเดอร์ android นี้" (รวม .github) → แท็บ Actions → build-apk → Run workflow → ดาวน์โหลด KruaPodeePOS-apk (app-debug.apk)
2. Android Studio: เปิดโฟลเดอร์ android → Build > Build APK(s)
ติดตั้ง: คัดลอก APK เข้าเครื่อง POS แล้วเปิดไฟล์ (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")

หมายเหตุ: ถ้าอัปโหลดผ่านเว็บแล้วโฟลเดอร์ .github ไม่ติด (โฟลเดอร์ซ่อน) ให้สร้างไฟล์เองที่ Add file → Create new file ตั้งชื่อ `.github/workflows/build.yml` แล้ววางเนื้อหาจากไฟล์ build.yml ในชุดนี้ และลบ workflow อัตโนมัติอันเก่าทิ้ง

## v1.1 — โหมดตรวจสอบเมื่อเชื่อมต่อไม่ได้
- หน้าต่าง "เชื่อมต่อระบบไม่ได้" แสดงรหัสข้อผิดพลาดจริง, รุ่น Android/WebView, วันเวลาเครื่อง และมีปุ่ม "ทดสอบเชื่อมต่อ" (เรียกเซิร์ฟเวอร์จากตัวเครื่องโดยตรง แยกปัญหาเครือข่าย/ใบรับรอง/วันเวลา ออกจาก WebView)
- แตะมุมซ้ายบน 7 ครั้ง → เมนู: เปลี่ยนที่อยู่ / ทดสอบเชื่อมต่อ / โหลดหน้าใหม่ / ล้างแคช

## v1.3 — ตั้งชื่อแอป/ที่อยู่ร้านต่อร้านได้
สร้าง APK ของแต่ละร้านโดยไม่ต้องแก้โค้ด: GitHub → Actions → build-apk → Run workflow แล้วกรอก
- ชื่อแอป (ชื่อใต้ไอคอนบนเครื่อง) · ที่อยู่ร้าน (ใส่แล้วแอปเปิดเข้าร้านเลย) · รหัสแอป (ไม่ซ้ำกันถ้าจะติดตั้งหลายร้านในเครื่องเดียว)
หรือรันเอง: `./gradlew assembleDebug -PappName="ชื่อร้าน" -PshopUrl=https://โดเมน/ร้าน/ -PappId=com.myshop.pos`
(ตัวอักษรพิเศษ ' " & < > @ % ? ในชื่อ/ที่อยู่จะถูกตัดออกอัตโนมัติ)

## v1.4 — โลโก้แอป + อ่านออกเสียงผ่าน TTS ของเครื่อง
- เปลี่ยนไอคอน/โลโก้: Run workflow แล้วใส่ "ลิงก์รูปโลโก้" หรืออัปโหลดไฟล์ `logo.png` ไว้ที่ repo (โฟลเดอร์เดียวกับ gradlew) — ระบบย่อเป็นไอคอนทุกขนาดให้เอง (แนะนำรูปสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใส 512×512)
- ชื่อแอปเปลี่ยนได้อยู่แล้ว (ช่อง ชื่อแอป ตอน Run workflow)
- ชื่อแอป/ที่อยู่ร้าน/รหัสแอป ตั้งถาวรได้ที่ 3 บรรทัด `MY_APP_NAME / MY_SHOP_URL / MY_APP_ID` บนสุดของ build-apk.yml (ใช้เมื่อเว้นช่องตอน Run workflow และตอน build จากการ push)
